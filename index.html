Firmware Installer

Install the firmware on your compatible ONX3248G035 ESP32-S3 touchscreen.

Before installation
  1. Use a Windows computer with Chrome or Edge.
  2. Connect the display with a USB data cable.
  3. Keep motor power disconnected during installation.
  4. Select the correct USB serial port when prompted.
  5. Wait until installation is complete before unplugging.
Please open this page in Chrome or Edge on a computer.

If installation fails, check the USB cable, driver and selected port. Do not disconnect the display while flashing.
